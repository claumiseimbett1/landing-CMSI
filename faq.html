¿Qué librerías Python específicas enseñan y qué nivel de profundidad en ML?

+

Librerías Python principales:

  • NumPy y Pandas: Manipulación de datos multidimensionales y análisis
  • Rasterio y GDAL: Lectura y procesamiento de imágenes geoespaciales
  • Matplotlib y Seaborn: Visualización de datos y resultados
  • scikit-learn: Algoritmos ML (Random Forest, SVM, k-means, PCA)
  • XGBoost: Gradient boosting avanzado para clasificación
  • OpenCV: Procesamiento de imágenes de drones
  • earthengine-api: Integración Python con Google Earth Engine

Nivel de profundidad en Machine Learning:

  • Intermedio-Avanzado: No solo uso de APIs, sino comprensión de hiperparámetros, validación cruzada, feature engineering
  • Algoritmos cubiertos:
    • Random Forest (clasificación y regresión)
    • Support Vector Machines (SVM)
    • k-means y clustering no supervisado
    • XGBoost para casos de alta dimensionalidad
    • PCA para reducción dimensional
  • Aplicaciones prácticas: Clasificación de cultivos, detección de anomalías, predicción de biomasa, segmentación de imágenes multiespectrales
  • NO se cubre: Deep Learning (TensorFlow/PyTorch) - el curso se enfoca en ML clásico optimizado para sensores remotos

Repositorio GitHub:

  • ✅ Acceso a repositorio privado exclusivo para alumnos
  • ✅ Más de 30 notebooks Jupyter comentados paso a paso
  • ✅ Scripts listos para producción en Python y JavaScript (GEE)
  • ✅ Datasets de ejemplo y casos de estudio reales
  • ✅ Actualizaciones continuas post-curso

Ejemplos de código incluidos:

  • Pipeline completo: descarga de Sentinel-2 → preprocesamiento → clasificación ML → exportación de mapas
  • Análisis temporal NDVI con detección automática de anomalías
  • Clasificación supervisada con validación de accuracy metrics
  • Integración GEE-Python para procesamiento batch
